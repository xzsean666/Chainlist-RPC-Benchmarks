# TASK-011: RPC 深度能力诊断（静态体检 + 新块状态验证）与直观报告体系

## 任务目标
将 `tmp/report.md` 中暴露的核心痛点完全集成到生产平台中：
1. 静态一次性能力体检（历史归档 Full Archive vs Pruned、CORS 直连支持、方法兼容性），仅测一次并永久缓存。
2. 动态轮次最新区块状态可用性监测（统计 `-32001 block not found` 发生次数与新块可读率）。
3. 集群负载均衡回退监测（Flapping 统计）。

- 排行榜表格中能直观看到归档标签、新块状态标签与避坑建议。
- 详情弹窗中能查看静态体检指标与工程避坑指南。
- 网页导航栏可打开并导出完整的深度诊断报告。
- 自动化测试全部通过，生产部署并验证成功。
